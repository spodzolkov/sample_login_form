# QA Manual Login Form App (`sample_login_form`)

Вебдодаток авторизації та реєстрації користувачів із бекендом на **Node.js (Express)** та веб-інтерфейсом на **HTML/CSS/JS**. Проєкт призначений для практики ручного та автоматизованого QA-тестування (інтеграційне тестування REST API за допомогою Jest та Supertest).

---

## 📋 Опис проєкту

Додаток реалізує повноцінний цикл авторизації та реєстрації користувачів із валідацією вхідних даних на стороні сервера та клієнта, а також збереженням даних у базі даних.

### Технологічний стек:
- **Backend**: Node.js, Express.js, CORS.
- **Database Engine**: `sql.js` (WebAssembly SQLite) з автоматичним збереженням у `database.sqlite`. У разі помилки WebAssembly використовується автоматичний фолбек на JSON-базу (`database.json`).
- **Frontend**: Vanilla HTML5, CSS3, JavaScript.
- **Testing Framework**: Jest, Supertest.

### Основний функціонал:
- Реєстрація нових користувачів (`POST /api/signup`) з перевіркою формату email, довжини та дублікатів.
- Авторизація існуючих користувачів (`POST /api/login`).
- Перегляд списку користувачів (`GET /api/users`).
- Перевірка стану сервера та бази даних (`GET /api/health`).
- Таблиця результатів / лідерборд (`GET /api/scores`, `POST /api/scores`).

## 🚀 Інструкція з локального запуску

### 1. Передумови (Prerequisites)
Переконайтеся, що на вашому комп'ютері встановлено:
- **Node.js**: версія `>= 16.x`
- **npm**: версія `>= 8.x`

Перевірити версії можна в терміналі:
```bash
node -v
npm -v
```

### 2. Кроки для запуску:

1. Перейдіть у папку проєкту `sample_login_form`:
   ```bash
   cd sample_login_form
   ```

2. Встановіть необхідні залежності:
   ```bash
   npm install
   ```

3. Запустіть веб-сервер:
   ```bash
   npm start
   ```
   *Також доступна команда `npm run dev`.*

4. Відкрийте браузер та перейдіть за адресою:
   ```text
   http://localhost:3000
   ```

### 3. Запуск автотестів:
Для перевірки REST API за допомогою тесті-кейсі на Jest виконайте:
```bash
npm test
```
Детальніше про автотести дивіться у файлі [TESTING_GUIDE.md](TESTING_GUIDE.md).

## 🌐 Інструкція з розгортання (Деплою) на Render.com

[Render.com](https://render.com/) — це хмарна платформа, яка дозволяє безкоштовно розгортати Web-сервіси Node.js.

### Покроковий гайд розгортання:

1. **Підготовка репозиторію:**
   - Переконайтеся, що всі зміни запушені у свій GitHub/GitLab репозиторій.

2. **Створення Web Service на Render:**
   - Зареєструйтесь або увійдіть у кабінет [Render.com](https://render.com/).
   - На робочому столі натисніть кнопку **New +** та оберіть **Web Service**.
   - Підключіть свій обліковий запис GitHub / GitLab та виберіть потрібний репозиторій.

3. **Налаштування параметрів деплою:**
   - **Name**: вкажіть назву вашого додатка (наприклад, `qa-sample-login-form`).
   - **Region**: оберіть найближчий регіон (наприклад, *Frankfurt (EU Central)*).
   - **Branch**: `main` (або `master`).
   - **Root Directory**: `sample_login_form` *(Обов'язково вкажіть це поле, якщо проєкт знаходиться у підпапці монорепозиторію!)*.
   - **Runtime**: `Node`.
   - **Build Command**: 
     ```bash
     npm install
     ```
   - **Start Command**: 
     ```bash
     npm start
     ```
     *(або `node server.js`)*.
   - **Instance Type**: `Free`.

4. **Змінні оточення (Environment Variables):**
   - Render автоматично призначає порт через змінну оточення `PORT`. Сервер у `server.js` вже налаштований на її зчитування: `const PORT = process.env.PORT || 3000;`. Додаткових обов'язкових змінних додавати не потрібно.

5. **Запуск деплою:**
   - Натисніть кнопку **Create Web Service**.
   - Зачекайте кілька хвилин, поки Render встановить залежності та виконає запуск.
   - Після завершення у верхній частині панелі з'явиться публічна URL-адреса вашого сервісу:
     ```text
     https://<ваша-назва-додатка>.onrender.com
     ```

6. **Перевірка роботи на Render:**
   - Перейдіть за отриманим посиланням у браузері, щоб перевірити роботу формочки входу.
   - Стан сервера можна перевірити за посиланням:
     ```text
     https://<ваша-назва-додатка>.onrender.com/api/health
     ```
